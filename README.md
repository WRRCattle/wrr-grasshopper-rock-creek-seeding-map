# Grasshopper Fire & Rock Creek Irrigation District — Aerial Seeding Concept Map

Draft terrain-only planning map for aerial broadcasting of compatible seed mixes inside the current `Burned Watershed ∩ Rock Zone` footprint.

## Important

This is not an executable drone mission. It does not clear obstacles, access, airspace, weather, operator requirements, agency permission, material calibration, or regulations. Existing LiDAR will be replaced before operational planning.

Open `index.html` through a web server. The public deployment uses GitHub Pages.

## Headline Estimate

- Selected planning footprint: 5,581.97 acres
- Aerial-compatible seed requirement: 70,406.63 lb PLS
- Base productive application time: 91.74 hours
- Base total flight time: 265.88 hours
- Base total operating time: 299.46 hours

Cost estimation is intentionally deferred until flight-time assumptions and bulk seed weights are refined.

See `RCDIC_Grasshopper_Aerial_Seeding_Concept_Report_2026-08-18_v1.md` for methods, assumptions, sources, and limitations.
